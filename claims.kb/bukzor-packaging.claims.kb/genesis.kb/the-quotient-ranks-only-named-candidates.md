# The Quotient Ranks Only Named Candidates

**`QUOTIENT` is complete over its candidates and silent about the candidate
set.** The set is authored, not given: a verdict is only as good as the best
rival anyone wrote down, and an unnamed rival with a higher ratio makes every
computed verdict wrong while leaving every computation correct.

The rivals this ledger systematically fails to name are the ones that route
around building -- they produce no artifact for a disposition row to point at:

- **upstream it** -- petition the product the wrapper patches: a bug report, a
  feature request, a PR;
- **buy it** -- adopt a tool that already exists elsewhere;
- **wait** -- let upstream drift resolve the need, the action that
  retroactively won on `claude-plan`;
- **write it down** -- deliver the knowledge as prose or config rather than
  code; `REUSE`'s artifact ladder already admits this rung, the candidate set
  should too.

The discipline the law buys: **a build or keep verdict names its best
non-build rival and prices it as a candidate** -- one line, same table. A
verdict with no named rival is a race with one runner.

## Smallest instance

`claude-uncolor` repairs ANSI-corrupted session records in place --
destructive, transcript-domain. If the corruption is upstream's defect, the
dominant rival is an upstream report; nobody has established whether it is,
and that is the point: no rival was ever enumerated, so the disposition was
computed over a candidate set of one. `claude-plan` is the completed case: the
action that won -- wait, then delete -- was never priced against the build it
retired.

## What would kill it

A closed population: nothing upstream to petition, nothing to buy, needs that
cannot lapse, consumers that cannot read prose. Pure personal glue approaches
that world; this population does not reach it -- most of its tools wrap one
product with a public issue tracker.
